INSTALLATION INSTRUCTIONS
───────────────────────────────────────────────────────────────────────────────

STEP 1: Clone Repository
  $ git clone https://github.com/trinnode/Tribute.git
  $ cd Tribute

STEP 2: Install Dependencies
  $ npm install

STEP 3: Build Extension
  $ npm run build

STEP 4: Load in Browser
  1. Open chrome://extensions/ (or brave://extensions/)
  2. Enable "Developer mode"
  3. Click "Load unpacked"
  4. Select the 'dist' folder

STEP 5: Test
  • Open demo.html or any webpage
  • Click the "Tip with Tribute" button
  • Configure and test features

PROJECT VISION
───────────────────────────────────────────────────────────────────────────────

"Tribute is the bridge between Bitcoin and the sovereign creator economy.
By leveraging sBTC on Stacks, Tribute upgrades Bitcoin tips from simple
A-to-B transactions into smart contracts capable of automatic revenue
splitting, yield generation, and on-chain reputation. We are not just
building a tipping tool; we are building the financial layer for the
sovereign creator economy."

KEY INNOVATIONS:
• Bitcoin tips → Smart contracts
• Simple transfers → Complex financial instruments
• Single recipient → Multiple beneficiaries
• Static amounts → Dynamic yield generation
• Anonymous → Verifiable reputation
